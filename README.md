## ⚙️ Repository Structure

- `nav/` - Ecosystem Directory landing page
- `veherego/` - VehereGo landing site and privacy policy
- `pyromagma/` - PyroMagma Academic and Reader landing sites
- `yourcallyourrule/` - YourCallYourRule landing site
- `llms.txt` & `llms-full.txt` - AI indexing specifications
- `sitemap.xml` & `robots.txt` - Web search engine sitemap and directives
- `.github/workflows/` - CI/CD release & store listing sync workflows
